# KYUNE — 웰니스 구독 박스

kyune.kr 홈페이지. 프리미엄 웰니스 큐레이션 박스(Direction A) 콘셉트의 구독형 서비스 사이트.

> "웰니스를 실천하는 사람들의 삶에 놓이는 오브제 박스"

## 구조

```
index.html      # 단일 페이지 사이트 (히어로 / 철학 / 이달의 박스 / 구독 플랜 / 저널 / FAQ)
css/style.css   # 스타일 — 리넨·스톤·우드 팔레트, Noto Serif KR
js/main.js      # 헤더 스크롤, 모바일 메뉴, 플랜 선택, 구독 신청 폼
```

빌드 도구 없이 정적 파일로 동작합니다. 로컬 확인:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구독 플랜

| 기간 | 월 요금 | 비고 |
|---|---|---|
| 1개월 | 119,000원 | 매월 자동 결제, 언제든 해지 |
| 3개월 | 112,000원 | 약 6% 할인 |
| 6개월 | 107,000원 | 약 10% 할인 · 웰컴 기프트 |
| 12개월 | 99,000원 | 약 17% 할인 · 리미티드 우선 구매 |

## 구독 신청 폼

현재는 사전 신청(웨이트리스트) 모드로, 신청 내역을 브라우저 `localStorage`
(`kyune-waitlist` 키)에 저장하고 완료 안내를 표시합니다.
결제/구독 백엔드가 준비되면 `js/main.js`의 submit 핸들러를 API 호출로 교체하면 됩니다.
